# Playing the current game

This guide covers the private alpha. You need Windows 11 x64 and the setup file
or portable game bundle. The game runs its own world server on your PC; you
can also connect to an approved world server on another machine. There is no
public server or multiplayer mode. [What works today](what-works.md) explains
the current limits.

- [Installation and connection](playing/installation-and-connection.md): Install the game, host a world and connect devices.
- [Creating a world](playing/creating-a-world.md): Create a world, configure its models and place the first Town.
- [Exploring the world](playing/exploring-the-world.md): Explore the map, inspect agents and buildings, and follow events.
- [Orders](playing/orders.md): Suggest actions and give agents orders for work and travel.
- [Town government](playing/town-government.md): Follow Town membership, government, law and public projects.
- [Settings and controls](playing/settings-and-controls.md): Pause the world, change settings and use controls and developer tools.
- [Saving and reporting](playing/saving-and-reporting.md): Save or recover worlds and report what you notice.
- [Households and animals](playing/households-and-animals.md): Follow households, children and animal care.
