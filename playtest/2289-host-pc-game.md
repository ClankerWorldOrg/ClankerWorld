# Play on the hosting PC

- [ ] On Windows, host a world and connect a second computer. Choose **Play on this PC**: the matching game opens with the same world, without an address or comparison code. The host window stays in the background.
- [ ] Quit the host-PC game and keep using the second computer. Confirm hosting and that device stay connected. With no games connected, confirm the existing idle/stop option still works.
- [ ] Repeat with a hosted Developer test world after changing the launcher's ordinary data choice. Confirm the game uses the hosted test world and usual saves/keys remain separate. No paid model call is required.
