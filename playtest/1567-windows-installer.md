# Per-user Windows setup

- [ ] On Windows 11 x64 as a standard user, run setup without administrator approval; the Start-menu shortcut opens the launcher and its bundled game plays a disposable world.
- [ ] Try the optional desktop shortcut, and confirm Windows Installed apps lists ClankerWorld Launcher.
- [ ] Run setup again, then a newer setup; installed game versions, a saved world, keys and model-call count remain available.
- [ ] Uninstall through Windows Settings; its confirmation explains that data is kept, and launcher files/shortcuts disappear while game versions and player data remain.
- [ ] Install again and play the retained disposable world with its original version.
