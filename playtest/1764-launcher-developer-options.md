- In the Windows launcher, turn Developer mode on and leave Use test data folder on. Play a new supported build, create and save a test world, then use Quit to Launcher. The test world is selected after Play; turn test data off and confirm your usual worlds and model settings are unchanged. Open saves folder and Open logs folder should follow the selected data folder. ([#1764](https://github.com/ClankerWorldOrg/ClankerWorld/issues/1764))
- With Developer mode on, turn Detailed logs on and Play. Open logs folder should contain game.log with extra engine detail and host.log with a detailed-launch line. Quit, turn Detailed logs off and Play again: the new logs should return to normal detail. Report a problem should include the current run's logs. ([#1764](https://github.com/ClankerWorldOrg/ClankerWorld/issues/1764))
- In Developer mode, choose Run a local build and select a locally built portable ClankerWorld.exe beside its host folder. It should start using the selected data and logging options. Choose an incomplete build or a build too old to support test data: the launcher should explain the refusal and keep your saves safe. Turn Developer mode off: all three Developer options should disappear and Play should use your usual data. ([#1764](https://github.com/ClankerWorldOrg/ClankerWorld/issues/1764))
