- On a fresh Windows account, extract the nightly portable zip and run `ClankerWorld.exe` without starting the server by hand. While it starts, the Main Menu says **Starting your world server…**. Within seconds the world choices become available without a server address or pairing code; create or open a disposable world, then quit and confirm the server closes. Start the game again and confirm it reaches the Main Menu with its saved connection. ([#2281](https://github.com/ClankerWorldOrg/ClankerWorld/issues/2281))
