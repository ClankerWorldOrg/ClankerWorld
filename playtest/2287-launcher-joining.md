- On a remote server: in the launcher choose **Join a world on another computer**, enter its HTTPS address and compare the code before approval. Choose a version and Play, then Continue. The game should enter the intended world without showing a pairing screen. Restart through the launcher and check that approval is remembered. ([#2287](https://github.com/ClankerWorldOrg/ClankerWorld/issues/2287))
- On a remote server: stop a known launcher or terminal host and choose Play. The launcher should say it cannot connect and explain how to start that kind of host if it is stopped. An approval refusal or a certificate problem should have its own message. ([#2287](https://github.com/ClankerWorldOrg/ClankerWorld/issues/2287))
- After joining a remote world, choose **Play on this PC**. Check that the local game still starts its own server without a code, and that selecting the saved remote connection again keeps local and remote worlds separate. ([#2287](https://github.com/ClankerWorldOrg/ClankerWorld/issues/2287))
