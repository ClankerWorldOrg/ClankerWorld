- With Developer mode on in a disposable paused world, open F12 → Edit world. Once the server offers editing tools, choose terrain and a kind, click or drag across several tiles, check the gold preview, then Apply; repeat with a resource. Confirm the map changes only after Apply, accepted edits appear as Developer edit, a refused edit shows its reason and changes nothing, and closing the tools or resuming clears the preview. The current alpha server's world editing remains unavailable. ([#2346](https://github.com/ClankerWorldOrg/ClankerWorld/issues/2346))
